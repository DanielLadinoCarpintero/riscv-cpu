# RV32I Pipelined RISC-V CPU

32-bit pipelined RV32I RISC-V processor written in SystemVerilog featuring forwarding, hazard detection, and a verification environment using ModelSim.

## Planned Features
- 5-stage pipeline
- Forwarding unit
- Hazard detection
- Branch handling
- Assertions
- Randomized testing
- Functional coverage

## Tools
- Quartus Prime
- ModelSim
- SystemVerilog
- Git/GitHub
